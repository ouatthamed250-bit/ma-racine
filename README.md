# Ma Racine — Projet de départ

Projet Next.js (TypeScript, App Router, Tailwind) avec le puzzle match-3 déjà
fonctionnel dans `src/components/MaRacinePuzzle.tsx`. Compilé et vérifié avant
livraison (`npm run build` passe sans erreur).

## Démarrage

```
npm install
npm run dev
```

Puis ouvre http://localhost:3000

## Où se trouve quoi

- `src/components/MaRacinePuzzle.tsx` — le jeu (moteur + UI)
- `src/components/MaRacinePuzzle.module.css` — ses styles
- `src/app/page.tsx` — l'affiche sur la page d'accueil
